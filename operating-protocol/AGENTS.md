# 작업 인계와 검토

- 조항을 바꿀 때 판본, 조항 키, 계기 단위, 출처와 사건 카드의 기대 경로를 확인합니다. 운전원 안내와 검색 결과에서 같은 조항으로 이동할 수 있게 유지합니다.
- 모든 작업을 마치면 본 작업과 파생 분기의 변경 사항을 코딩관리자에게 검토받습니다. 변경 경로와 변경 종류, 확인한 동작, 검증 결과와 미결 사항을 함께 전달합니다.
- 코드 변경은 객체별 책임, 데이터와 판본의 검증, 실패 처리, 공개 명령의 동작, 관련 테스트를 검토합니다. 문서·데이터 변경은 변경 종류와 코드 구조 검토의 해당 여부를 기록하고 명령, 조항과 출처의 일치를 확인합니다.
- 병합 전에 검토 결과와 반영한 사항을 변경 기록에 남깁니다.
